# HPCM — Log Explorer

A Grafana dashboard for exploring and analyzing logs from an HPCM (HP Cluster Manager) environment using VictoriaLogs. Provides a full-stack view of log volume, distribution, error trends, and live log streaming — filterable by node, log level, and log stream.

> **Dashboard:** `HPCM — Log Explorer`
